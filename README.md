# TripMaxxing

**Plan smarter. Travel better.**

TripMaxxing is a personalized travel planner that turns a traveler's destination, dates, budget, interests, dietary needs, and preferred pace into a practical day-by-day itinerary.

## What TripMaxxing will do

- Build a schedule of attractions, restaurants, and activities that fits the user's available time.
- Keep estimated activity and food costs within the user's trip budget.
- Recommend places based on interests, ratings, dietary needs, and travel pace.
- Arrange stops in a sensible order and show approximate travel times.
- Display estimated costs, opening hours, booking needs, and map links for each stop.
- Suggest lower-cost alternatives when the user wants to save money.
- Let the user swap an activity or regenerate the plan when preferences change.
- Provide weather-aware guidance and simple outfit suggestions.
- Offer alternative activities for spontaneous changes during the trip.

## Initial experience

The first version will plan one- to three-day trips in New York City using curated sample travel data. Users will be able to change their budget or preferences and receive a newly generated itinerary with updated schedules, costs, and alternatives.

Google sign-in and trips saved in this browser are available now. Live place, route, event, and weather features are planned for later versions.
